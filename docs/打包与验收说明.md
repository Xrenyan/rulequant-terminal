# RuleQuant 打包与验收说明

## 本包定位

本包用于普通用户试用 RuleQuant 回测终端。系统只用于历史开奖数据分析、用户提供公式计算、逐期明细核对、综合参考排序，不提供保证结果或投注建议。

## 启动方式

Windows 用户解压后双击：

```text
start-rulequant-windows.bat
```

启动脚本会：

1. 检查 Node.js；
2. 自动启用 pnpm；
3. 第一次运行时安装依赖；
4. 使用已经打包好的生产构建启动；
5. 自动选择 3000-3004 中可用端口；
6. 自动打开首页。

## 本次重点修复

- 每天同步网站数据后会写入本地开奖库，不再只是临时预览；
- 打开首页、开奖数据、公式明细、综合参考等核心页面时，当天会自动同步一次；
- 开奖数据页增加“同步并写入本地库”按钮，并显示最新期、记录数和最后同步时间；
- 综合参考结果按已启用、可计算、未手动排除的用户提供公式生成，不再因样例未核对而变成 0 条参与；
- 公式逐期明细默认展开变量取值、公式原文、原始结果和归一化过程；
- 公式逐期明细去掉内部小滚动条，方便整页阅读；
- 最新一期即使还没有下一期开奖，也会显示在公式逐期明细最上方，并标记为“待验证”；
- 2026176 期已经能在公式逐期明细中显示完整计算过程，不再只显示到 2026175；
- D序只排序 6 个平码，特码单独保留；
- 期合 / 期合尾按后三位期数计算；
- 含未确认“位”变量的规则标记待确认，不乱算；
- 页面切换时只计算当前页面需要的数据，降低无关页面点击卡顿；
- 启动脚本改为生产模式，避免朋友试用时一直跑开发模式。

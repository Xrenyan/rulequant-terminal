# RuleQuant 线上共享版部署说明

## 目标

线上共享版用于让朋友直接打开网址使用，不再传压缩包。

上线后：

1. 程序 Bug 修复、UI 修改、公式引擎修改：通过重新部署自动同步给所有人。
2. 开奖数据：由服务器定时任务每天自动同步到数据库。
3. 朋友访问同一个网址，读取同一份云端开奖数据和内置公式。

## 推荐平台

- 网站部署：Vercel
- 数据库：Vercel Marketplace 里的 Postgres，例如 Neon / Supabase / Prisma Postgres
- 自动同步：Vercel Cron Jobs

## 必填环境变量

在 Vercel 项目的 Environment Variables 中添加：

```env
DATABASE_URL=postgres://USER:PASSWORD@HOST:PORT/DATABASE?sslmode=require
CRON_SECRET=一串随机密钥
RULEQUANT_ADMIN_TOKEN=一串管理员密钥
RULEQUANT_DRAW_SOURCE_URL=https://thjffv.ag0rkv-4pnok-ljvvrg.xyz:16633/kj/3/2026.html
RULEQUANT_SYNC_FROM_YEAR=2026
RULEQUANT_SYNC_TO_YEAR=2026
```

说明：

- `DATABASE_URL`：云端数据库连接地址。
- `CRON_SECRET`：保护定时任务接口，防止别人乱触发。
- `RULEQUANT_ADMIN_TOKEN`：保护云端状态写入接口，防止朋友误改全局公式库。
- `RULEQUANT_DRAW_SOURCE_URL`：开奖数据来源网址。
- `RULEQUANT_SYNC_FROM_YEAR / RULEQUANT_SYNC_TO_YEAR`：同步年份。

## 每天自动同步

项目里的 `vercel.json` 已配置：

```json
{
  "crons": [
    {
      "path": "/api/cron/sync-draws",
      "schedule": "30 16 * * *"
    }
  ]
}
```

Vercel Cron 使用 UTC 时间。`30 16 * * *` 大约是北京时间每天 00:30。

## 手动测试同步

部署后可以访问：

```text
https://你的域名/api/cron/sync-draws
```

如果设置了 `CRON_SECRET`，手动请求需要带：

```text
Authorization: Bearer 你的CRON_SECRET
```

成功后会返回：

```json
{
  "ok": true,
  "latestIssue": "最新期号",
  "recordCount": 记录数量
}
```

## Bug 怎么同步给朋友

以后修 Bug 的流程：

1. 修改代码。
2. 本地跑测试和构建。
3. 提交到 GitHub。
4. Vercel 自动重新部署。
5. 朋友刷新网页，就会看到新版本。

朋友不需要重新下载安装包。

## 当前兼容策略

如果没有配置数据库：

- 本地桌面包仍然能用；
- 浏览器本地数据仍然保存；
- 定时任务不会影响本地使用。

如果配置了数据库：

- 首页和各页面优先读取云端开奖数据；
- 数据库为空时，定时任务会自动写入开奖数据、内置公式和默认配置；
- 公式引擎、UI、Bug 修复通过部署同步。

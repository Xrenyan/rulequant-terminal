# RuleQuant 交付审核说明

## 项目定位

RuleQuant 是规则型开奖数据公式回测终端。系统只用于历史数据分析、公式计算、样例核对、逐期明细、综合参考排序。

系统页面和说明均避免使用：

- 必中；
- 稳赚；
- 包准；
- 精准预测；
- 一定会开；
- 投注建议。

可使用的表述：

- 综合参考结果；
- 参考号码；
- 参考生肖；
- 公式研究结果；
- 候选排序；
- 仅供参考。

## 公式状态逻辑

用户提供的内置公式属于“用户提供公式”。

只要满足以下条件即可参与综合参考：

- 已启用；
- 可计算；
- 没有变量识别错误；
- 公式类型明确；
- L序 / D序明确；
- 没有未确认的“位”变量；
- 没有被用户手动标记为不参与。

样例核对只是用来检查程序是否理解正确，不是参与综合参考的强制门槛。

可接受状态示例：

```text
已启用公式 33 条
可计算公式 33 条
参与综合参考公式 33 条
样例已核对 0 条
样例未核对 33 条
```

不可接受状态：

```text
启用公式 33 条
参与综合参考公式 0 条
综合结果全是 0 分
```

## 推荐审核流程

1. 打开 `/dashboard`。
2. 点击“同步最新开奖数据”。
3. 确认显示最新期号、开奖号码、数据来源、同步时间。
4. 进入 `/one-click`，点击“一键计算全部公式”。
5. 进入 `/candidate-pool`，点击“重新生成综合参考结果”。
6. 确认“实际参与公式”不是 0。
7. 确认“本次生成证据”不是 0。
8. 点击 Top 号码，查看支持证据和反对证据。
9. 进入 `/formula-detail`，查看某条公式的逐期流水账。
10. 进入 `/formula-editor?mode=new`，确认是空白新增表单。
11. 输入草稿公式，点击“试算当前公式”。
12. 保存为新公式，确认不会覆盖旧公式。
13. 进入 `/rules`，测试启用、停用、删除、备份、恢复。

# 2026-09-26 流畅度与错期观察更新

## 用户可见变化

- 设置 → 公式自动管理：正式公式错一期后，接下来三个实际开奖暂停参与新的综合参考；继续记录观察结果，可提前恢复，默认三期满后自动恢复。
- 公式管理 → 暂停观察：查看暂停原因、三期进度、错期计算和最近变化；顶部统一提醒，不为每条公式重复弹窗。
- 计算结果按需要取完整过程，跨页复用未改变的历史计算；页面不再重复搬运全部详细过程。
- 200 期矩阵仍覆盖全部期次、全部结果和 0 次结果；增加期次查找、跳转，长列表只绘制当前视口附近的行。
- 图表放大保留同一实例、选择及滚动位置；长趋势保留全部点，横向查看而不把 200 个触控点挤在一起。
- 公式健康列表支持全部搜索与分页，展开后才加载对应说明。公式列表返回时保留筛选与页码。
- 手机设置分成整齐的两行入口；暂停提示、按钮反馈、浅深色层次和键盘焦点保持原有视觉体系，采用轻量短动效。
- 补齐号码公式 177–188，公式库 246 → 258 条，原有 246 条记录未改动。期数头、期数合尾、总分合尾等口径已统一并附使用说明。

## 不变的边界

- 没有删除历史数据、偷偷缩短所选分析期数，也没有把历史统计当成未来保证。
- 暂停只影响之后新生成的参考，不改写已有参考、历史统计、公式本身或手动停用状态。
- 观察状态保存在当前浏览器，不跨设备同步；网页关闭时不会发站外通知，下次打开并更新开奖后补记。
- 启用前的历史错误不批量触发暂停；缺失、未开奖和计算异常不当成错期。
- 首次完整计算和完整导出仍需要一定时间；性能记录中的传递体积缩减不等于网页整体提速比例。

## 设计参考

参考 [ColorOS 17 官方介绍](https://www.coloros.com/version/coloros17/) 中视效、动效、触控反馈一致的方向，只调整本项目的小范围反馈与布局，不替换原有 iOS 风格，不增加大面积模糊或长动画。

已对自动暂停的跨期、补齐、更正、提前恢复和手动排除边界，以及计算缓存失效、完整过程与导出保真增加回归测试。最终 78 个测试文件、473 项测试通过，类型检查和代码检查通过；正常构建通过。浏览器验收覆盖桌面和手机、浅深色设置、200 期矩阵与放大、实际公式贡献追溯，以及带 GitHub Pages 路径前缀的静态页面。另补了放大图的滚动恢复、颜色继承与手机开奖标记回归。

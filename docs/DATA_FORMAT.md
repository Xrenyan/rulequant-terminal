# RuleQuant 数据格式

## 开奖数据

CSV / Excel / JSON 字段：

```json
{
  "issue": "2026156",
  "date": "2026-06-05",
  "n1": 4,
  "n2": 15,
  "n3": 20,
  "n4": 29,
  "n5": 34,
  "n6": 42,
  "special": 46
}
```

中文字段也可识别：

- `期号` -> `issue`
- `日期` -> `date`
- `平1` / `落1` -> `n1`
- `平2` / `落2` -> `n2`
- `平3` / `落3` -> `n3`
- `平4` / `落4` -> `n4`
- `平5` / `落5` -> `n5`
- `平6` / `落6` -> `n6`
- `特码` / `特号` / `平7` / `落7` -> `special`

## TXT 粘贴格式

无表头也可以：

```text
2026166 8 13 19 27 35 44 6
```

顺序为：

```text
issue n1 n2 n3 n4 n5 n6 special
```

## 自动校验

导入前会检查：

- 每行必须有期号和 7 个号码
- 号码必须是 1-49 的整数
- 重复期号会提示
- 导入后自动计算 L序、D序和属性

# RuleQuant 回测终端开发说明

这份说明用于转发给规则提供者、协作者或试用者，解释本次开发做了什么以及系统如何工作。

## 产品定位

RuleQuant 是一个规则型开奖数据公式回测终端。它的目标是把历史开奖数据、规则公式、手算样例和回测结果放到同一个专业工具里，帮助用户核对规则口径和分析历史表现。

系统不接入支付或资金决策链路。所有输出都只是规则回测和历史数据分析，不作为任何资金决策依据。

## 当前能做什么

- 导入 CSV、TXT、Excel 开奖数据。
- 抓取每天更新的开奖网页，先参与研究计算，再按需写入本地库。
- 自动生成 L序、D序、特码属性和总数属性。
- 优先使用网页记录自带的生肖、五行、波色属性，减少历史属性切换带来的误差。
- 新增、编辑、复制、启用、禁用、删除规则。
- 运行规则回测，查看成功率、错期、连对和逐期计算过程。
- 查看规则共识候选池，切换 Top 7/8/9 生肖和 Top 16/18 号码。
- 点击候选项查看支持证据和反对证据。
- 录入手算样例，和程序计算结果对比。
- 不一致时显示差异类型，例如公式结果、归一化、生肖映射、验证结果。
- 导出开奖数据、规则库、配置、回测结果、候选池报告、样例校验报告和 HTML 报告。

## 规则如何计算

系统默认使用第 N 期数据计算规则输出，再用第 N+1 期的特码属性验证。八肖管两期会验证 N+1 和 N+2 两期。

每期明细都会保留：

- 当前期号和号码
- L序、D序
- 公式和变量取值
- rawResult
- 归一化步骤
- finalResult
- 映射结果
- 下一期属性
- 成功或失败

## 如何运行

```bash
npm install
npm run dev
```

打开本地地址后进入 `/dashboard`。

# 错期暂停观察

首次发布使用浏览器本地 `rulequant:wrong-period-observation:v2` 记录，状态版本为 2。开发期间短暂使用的 v1 记录不迁移、不读取，也不删除；它不是已发布的用户记录。这样不会把开发调试阶段按旧快照补历史产生的暂停带入正式功能。

## 参与与观察

- 完整开奖确认公式未通过后，接下来三个实际完整开奖只做观察，不参与新的综合参考；原有历史记录不改写。
- 暂停不是停用公式。`enabled`、`participatesInReference`、公共公式种子和云端数据都不会被自动管理改写。
- 提前恢复只影响之后的参与。旧错期不会重复触发；观察期间再错也不会重新倒计时。
- 默认满三期自动恢复；关闭自动恢复后等待手动操作。手动停用的公式不会被自动启用。
- 关闭整个自动暂停功能会解除当前观察；再次开启从最新已检查期号和重新开启日期开始。

## 新旧数据边界

- 首次启用先等待一次开奖来源检查完成，以最新可用完整期号建立起点，不追罚已有历史。
- 已有起点的用户无需等待每次后台联网完成即可使用已保存的观察状态。
- 若首次只能取得旧快照，之后补入的、严格早于启用日的历史开奖不触发暂停；日期按澳门/上海时区判断。只有日期而无时刻时，同日仍以期号起点判断；没有日期时只能依赖期号起点。
- 多期公式必须等整个核对窗口结束；缺失、未开奖、计算异常不是错期。不能把缺失后下一条记录当作“下一期”。

## 更正、补齐与恢复

- 重复相同开奖只算一次；同一期有冲突版本时不作为可信开奖。
- 观察期后来补齐时，按真实期号排序计入，不能重复计数，也不能触发旧错期新暂停。例如 268 期暂停，先有 270 期，后来补齐 269 期，则观察记录为 269、270 两期。
- 数据更正会重新核对当前观察样本，不延长暂停。原错期或其计算依据有更正时，显示“原核对有更正，请复核”，保留当时暂停原因，允许用户立即恢复。
- 三期补齐完成后，对之后的参考恢复参与，不重写已经生成的历史参考。

## 存储及提醒

记录按当前浏览器保存，不自动跨设备同步。网页关闭时不提供后台推送；下次打开并更新开奖时补记。批量变化由页面统一提示，最近 500 条变化可查看。存储权限或容量异常必须显示提示，不能静默承诺已保存。

此功能是管理参与状态和复核过程，不意味着可以提高未来命中率。
